## HireFlow AI frontend

This is the [Next.js](https://nextjs.org) frontend for HireFlow AI, an AI hiring platform for candidate sourcing, recruitment campaigns, and Hunar-powered voice screening.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to use HireFlow AI. See the [root README](../README.md) for setup, configuration, testing, and deployment instructions.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
